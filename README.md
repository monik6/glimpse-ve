# glimpse-ve
Glimpse is a Google Slides add-on designed to help laymen create virtual exhibitions quickly and easily, with high-quality graphics and interactive features.

**Glimpse Code Instructions**
Open Google Chrome.
Open Google Slides and name the file as "GlimpseVE".
Go to Extensions and select "Apps Script". Name this file also as "GlimpseVE".
Open the provided Code text file and paste it in Code.gs
Next, create 7 files using the "+" icon with the following names: 
Sidebar                      use HTML
index                        use HTML
theme1_Template              use Script
sheetToSlideDataEntry        use Script
formcreation                 use Script
presentationThemeCopy        use Script
loadingStructure             use HTML

Make sure that the file names and types are correct before continuing.
Copy the code from the respective text files with the same names and paste them onto your Apps Script Project.
Once all 8 files are added, click on "Deploy" > "New Deployment" > "Add Description". Change the "Execute as" and "Who has access" settings to the following:
"Execute as": "User accessing the web app"
"Who has access": "Anyone with Google account"
Copy the web app URL and go to "Sidebar.html". Paste it in 2 places where the following comment has been mentioned.
Open the container Google Slide file named "GlimpseVE" and run Glimpse by clicking on the "Extensions" menu.
The Glimpse Virtual Exhibition Framework should now be available to use.
